# 📝 MERN TodoList App (Full CRUD)

A full-stack **Todo List Web Application** built using the **MERN Stack** (MongoDB, Express.js, React.js, Node.js).  
This app allows users to **Create, Read, Update, and Delete tasks** with persistent storage in MongoDB.

---

## 🚀 Features

- ➕ Add new todo tasks  
- 📋 View all tasks from database  
- ✏️ Edit tasks inline  
- ❌ Delete tasks  
- ⚠️ Prevent delete while editing (alert shown)  
- 💾 Data stored in MongoDB  
- 📱 Fully responsive UI  
- 🎨 Clean & modern design  

---

## 🛠 Tech Stack

### Frontend
- React.js (Vite)
- HTML5
- CSS3
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS
